RECURSOS UTILIZADOS (conforme apostila)
---------------------------------------------

HTML:
- Estrutura semântica: header, nav, main, section, footer
- Tabelas: table, tr, th, td, thead, tbody
- Formulários: form (method GET), input, select, textarea, label
- Mapa clicável: img usemap, map, area (rect, circle, poly)
- Google Maps: iframe embed
- Âncoras: id + href="#id"
- Listas: ul, ol, li
- Links: target="_blank", rel="nofollow"

CSS:
- Reset universal (seletor *)
- Seletor html { font-size: 62.5% } → base rem
- Unidade rem para fontes
- Bordas (border)
- Cores (background-color, color)
- Responsividade: clamp(), display: flex, @media
- Grid: grid-template-columns, gap, fr, repeat()
- Hover e transition
- position: fixed (header)
- text-shadow
- rgba (transparência)

JavaScript:
- alert() com caracteres de escape (\n, \")
- Funções: function
- Variáveis: var
- Operações aritméticas (cálculo de orçamento)
- document.getElementById()
- new Date() para data atual
